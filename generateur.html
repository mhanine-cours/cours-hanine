Tapez les commandes comme dans NI MAX (« Communiquer avec l'instrument ») ou dans un VISA Write. Plusieurs commandes se séparent par « ; ». Les réglages faits à la souris s'affichent aussi ici.

Exemples :

Le même message dans LabVIEW

Bloc Formater en chaîne (format), puis VISA Write sur GPIB0::9::INSTR :

%.;:FUNC SIN;:FREQ %g;:VOLT:AMPL %.3f;:VOLT:OFFS %.2f;:OUTP ON\n

Chaîne effectivement envoyée avec les réglages actuels :

« %.; » impose le point décimal : l'appareil refuse la virgule. Le « \n » (LF, 0x0A) termine chaque message.

Défis

Réglez le banc pour obtenir le signal demandé (souris ou console), puis cliquez sur « Vérifier ».
