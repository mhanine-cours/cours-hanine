Saisissez un nombre dans la base de votre choix : les quatre écritures s'affichent, avec la méthode détaillée.

📘 Rappel de cours et exemples afficher / masquer

1. Le principe : une numération de position

Dans une base b, on utilise b chiffres (de 0 à b − 1) et chaque chiffre a un poids qui est une puissance de b selon sa position (en partant de la droite, position 0).

N = an×bn + … + a2×b2 + a1×b1 + a0×b0
BaseNomChiffresNotation en C
2binaire0, 10b1011 (selon compilateur)
8octal0 à 7013
10décimal0 à 911
16hexadécimal0 à 9, A(10) à F(15)0xB

2. Base b → décimal : on développe en puissances

Exemple10112 = 1×23 + 0×22 + 1×21 + 1×20 = 8 + 0 + 2 + 1 = 11
2D16 = 2×161 + 13×160 = 32 + 13 = 45

3. Décimal → base b : divisions successives par b

On divise par b jusqu'à obtenir un quotient nul ; le résultat est la suite des restes lus de bas en haut.

Exemple : 13 en binaire13 ÷ 2 = 6 reste 1 · 6 ÷ 2 = 3 reste 0 · 3 ÷ 2 = 1 reste 1 · 1 ÷ 2 = 0 reste 1
Lecture de bas en haut : 13 = 11012

4. Binaire ↔ hexadécimal et octal : par groupes de bits

16 = 24 : un chiffre hexadécimal correspond à 4 bits ; 8 = 23 : un chiffre octal correspond à 3 bits. On groupe à partir de la droite.

Exemple : 156156 = 1001 11002 → 1001 = 9, 1100 = C → 9C16
156 = 010 011 1002 → 2, 3, 4 → 2348
⚠ Pièges fréquents : lire les restes de haut en bas (c'est l'inverse) ; oublier de compléter le dernier groupe par des 0 à gauche ; écrire « 12 » au lieu de « C » en hexadécimal.

A retenir : avec n bits, on représente 2n valeurs, de 0 à 2n − 1 (8 bits : 0 à 255).

Complément à 2

C'est ainsi que le type char (8 bits) ou short (16 bits) stocke un entier négatif.

📘 Rappel de cours et exemples afficher / masquer

1. Pourquoi le complément à 2 ?

L'ordinateur n'a pas de signe « − » : il code les entiers négatifs de sorte que l'addition binaire ordinaire donne le bon résultat. C'est la représentation des types signés en C (char, short, int).

Sur n bits : de −2n−1 à 2n−1 − 1 (8 bits : −128 à 127 ; 16 bits : −32 768 à 32 767)

2. Coder un entier négatif −x sur n bits

  1. écrire x en binaire sur n bits ;
  2. inverser tous les bits (complément à 1) ;
  3. ajouter 1.
Exemple : −5 sur 8 bits5 = 0000 0101 → inversion : 1111 1010 → +1 : 1111 1011 (= FB16)
Vérification : 256 − 5 = 251 = 1111 10112

Astuce rapide : en partant de la droite, on recopie les bits jusqu'au premier 1 inclus, puis on inverse tous les bits suivants.

3. Décoder un mot

Si le bit de poids fort vaut 0, le nombre est positif ; s'il vaut 1, il est négatif : on refait « inverser + 1 » pour trouver sa valeur absolue.

Exemple1111 1011 → bit de poids fort à 1 → inversion : 0000 0100 → +1 : 0000 0101 = 5 → le nombre vaut −5

4. L'addition marche directement

Exemple : 5 + (−3) sur 8 bits0000 0101 + 1111 1101 = 1 0000 0010 = 2 (la retenue qui sort du 8e bit est ignorée)
⚠ Débordement : en C, char c = 100 + 50; ne vaut pas 150 (hors de −128…127) mais 150 − 256 = −106.

📘 Rappel de cours et exemples afficher / masquer

1. Le format d'un float (32 bits)

Signe sExposant EMantisse M
1 bit8 bits (biais 127)23 bits
x = (−1)s × 1,M × 2E − 127

Le « 1, » devant la mantisse n'est pas stocké (bit implicite). Le double suit le même principe sur 64 bits (11 bits d'exposant, biais 1023, 52 bits de mantisse).

2. Méthode d'encodage en 5 étapes

  1. signe : 0 si positif, 1 si négatif ;
  2. écrire |x| en binaire (partie entière par divisions, partie décimale par multiplications successives par 2) ;
  3. normaliser sous la forme 1,… × 2e ;
  4. exposant stocké E = e + 127, sur 8 bits ;
  5. mantisse = les bits après la virgule, complétés par des 0 jusqu'à 23 bits.
Exemple : 5,755 = 101 ; 0,75 × 2 = 1,5 → 1 ; 0,5 × 2 = 1,0 → 1 ; donc 5,75 = 101,112 = 1,0111 × 22
s = 0 ; E = 2 + 127 = 129 = 1000 0001 ; M = 0111 0000…
→ 0 10000001 01110000000000000000000 = 40B8000016
Exemple : −0,50,5 = 0,12 = 1,0 × 2−1 ; s = 1 ; E = −1 + 127 = 126 = 0111 1110 ; M = 0 → BF00000016
⚠ 0,1 s'écrit 0,000110011001100… en binaire (suite infinie) : il est arrondi. C'est pourquoi, en C, on ne teste jamais l'égalité de deux réels avec == mais fabs(a − b) < 1e-6.

Codes binaires : BCD, Excess-3, Aiken et Gray

Ces codes ne servent pas à calculer mais à représenter l'information : afficheurs 7 segments, compteurs, codeurs de position…

📘 Rappel de cours et exemples afficher / masquer

1. Le code BCD (Binary Coded Decimal, 8421)

Chaque chiffre décimal est codé séparément sur 4 bits, avec les poids 8, 4, 2, 1. Seuls les mots 0000 à 1001 sont utilisés ; 1010 à 1111 sont interdits.

Exemple59 → 5 = 0101, 9 = 1001 → 0101 1001 (BCD) — alors que 59 en binaire naturel = 11 1011
Addition en BCD : 8 + 51000 + 0101 = 1101 : résultat supérieur à 9 (code interdit) → on ajoute 6 (0110) : 1101 + 0110 = 1 0011 → 0001 0011 = 13

2. Le code Excess-3 (XS-3)

On code chaque chiffre augmenté de 3. Avantage : le complément à 9 s'obtient en inversant les bits (pratique pour les soustractions).

Exemple47 → 4 + 3 = 7 = 0111 ; 7 + 3 = 10 = 1010 → 0111 1010

3. Le code Aiken (2421)

Code pondéré (poids 2, 4, 2, 1), lui aussi auto-complémentaire : 5 = 1011, 9 = 1111.

4. Le code Gray (binaire réfléchi)

Entre deux valeurs consécutives, un seul bit change : on l'utilise dans les codeurs de position (roues codeuses) et les tableaux de Karnaugh.

gn = bn ; gi = bi+1 ⊕ bi
bn = gn ; bi = bi+1 ⊕ gi
Exemple : 6 = 110 en Grayg2 = 1 ; g1 = 1 ⊕ 1 = 0 ; g0 = 1 ⊕ 0 = 1 → 101
3 = 0010 et 4 = 0110 en Gray : un seul bit diffère.

A retenir : ⊕ (OU exclusif) vaut 1 si les deux bits sont différents, 0 s'ils sont égaux.

Caractères ASCII

En C, un caractère est un petit entier : 'A' == 65.

📘 Rappel de cours et exemples afficher / masquer

1. Un caractère est un nombre

Le code ASCII associe à chaque caractère un entier de 0 à 127 (7 bits). En C, le type char stocke ce nombre.

2. Exemples en langage C

Calculs sur les caractères'A' + 1 vaut 66, c'est-à-dire 'B'
'7' - '0' vaut 7 : c'est ainsi qu'on convertit un chiffre lu en sa valeur
'a' - 32 vaut 'A' : majuscule et minuscule sont séparées de 32
Afficher un codeprintf("%c = %d = 0x%X\n", 'A', 'A', 'A'); affiche A = 65 = 0x41
⚠ Ne pas confondre le caractère '5' (code 53) et le nombre 5. Les lettres accentuées (é, à…) ne font pas partie de l'ASCII de base.

Méthode pour réussir les exercices

  • Vers le décimal : écrivez les poids (1, 2, 4, 8, 16… ou 1, 16, 256…) au-dessus des chiffres, puis additionnez.
  • Depuis le décimal : posez les divisions successives et lisez les restes de bas en haut.
  • Binaire ↔ hexadécimal : groupes de 4 bits en partant de la droite.
  • Complément à 2 : valeur absolue sur 8 bits, inversion, +1. Vérifiez : 256 − |x|.
  • BCD / Excess-3 : 4 bits par chiffre (et +3 pour l'Excess-3).
  • Gray : premier bit recopié, puis OU exclusif des bits voisins.

Vérifiez toujours votre réponse par la conversion inverse. Si vous vous trompez, la correction détaillée s'affiche : refaites ensuite un exercice du même type.
